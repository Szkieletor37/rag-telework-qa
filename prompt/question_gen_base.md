# 役割
あなたはRAG（検索拡張生成）評価用の高品質なテストデータセット（ベンチマーク）を作成するAIデータエンジニアです。

# 目的
* 厚生労働省の「テレワークの適切な導入及び実施の推進のためのガイドライン」（Markdown）を【資料】として提供します。
* 指定された【カテゴリー指示】に従って、【資料】に関して、RAGアプリケーションの性能検証用の質問セットを5問生成してください。

# 背景とペルソナ
* ユーザーペルソナ:
  - 企業の人事担当者 
  - テレワーク導入・推進を担当するために、厚生労働省のガイドラインを参照しようとして、RAGアプリケーションを用いる
* 利用シーン:
  - テレワーク導入のための準備・調査段階（ポイント、留意点など）
  - ルールの策定・周知のためのポイント・注意点
  - 労務管理・労働時間管理・安全衛生のルール化や、実施時のポイント
  - 制度の利用の検討、ハラスメント・セキュリティなど、万一の際の対応の検討

# 質問のバリエーション（均一化防止の制約）
以下の観点をばらけさせて作成してください：
- タスク種別（制度設計 / 労務管理 / 労働時間制度活用 / 安全衛生 / etc...）
- 難易度（基本 / 細かい / 条件が複雑 / etc...）

# 出力フォーマット
出力は解説文を一切含めず、**以下のYAML形式のみ**を直接出力してください。
各フィールドの文字列は、記号によるパースエラーを防ぐため必ずダブルクォーテーション `"` で囲んでください。

```yaml
- question_id: 1
  # 質問カテゴリー
  category: "conditional"
  # 人事担当者が厚生労働省のガイドライン（telework_guide.md）に対して調べるリアルな質問文
  question: "労働者が専らモバイル勤務をする場合など、働く場所を柔軟に運用する際、就業の場所の明示や就業規則での規定はどのように対応すべきですか？"
  # ideal_chunks に基づく模範解答
  ground_truth: "専らモバイル勤務をする場合等、働く場所を柔軟に運用する際は、使用者の許可基準を示した上で、就業規則や労働条件明示において「使用者が許可する場所」として明示・規定することが可能です。"
  ideal_chunks:
    - chunk_id: 1
      # 回答の根拠となる原文の該当箇所（【２】 就業規則整備のポイント より抜粋）
      source_excerpt: "テレワークを行う場所について、労働者が専らモバイル勤務をする場合や、いわゆる「ワーケーション」の場合など、労働者の都合に合わせて柔軟に選択することができる場合には、使用者の許可基準を示した上で、「使用者が許可する場所」においてテレワークが可能である旨を定めておくことが考えられます。"

    - chunk_id: 2
      # 回答の根拠となる原文の該当箇所（【３】 労働条件明示のポイント より抜粋）
      source_excerpt: "労働者が専らモバイル勤務をする場合等、業務内容や労働者の都合に合わせて働く場所を柔軟に運用する場合<br>就業の場所についての許可基準を示した上で、「使用者が許可する場所」といった形で明示することも可能です。"
